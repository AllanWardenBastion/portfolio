# 💻 Portfolio - Allan Mulot

Bienvenue sur mon portfolio de développeur web 👋

## 🚀 À propos

Je suis actuellement en formation pour devenir développeur web.  
Je me forme aux bases du développement front-end (HTML, CSS, JavaScript) et je commence à explorer le back-end avec Node.js.

Ce portfolio a pour objectif de présenter mes compétences, mes projets et mon évolution dans le domaine du développement.

---

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- ScrollReveal (animations)
- Typed.js (texte animé)

---

## 🎯 Fonctionnalités

- Navigation fluide entre les sections
- Design responsive (mobile / tablette / desktop)
- Animations au scroll
- Effet de texte dynamique
- Section projets (portfolio)
